Admin – update the data (Chennai & ROTN)

Version 15 · For the branch only. Nothing is uploaded anywhere: the Excel file is read inside your browser.

1. Choose the new daily Excel file

Columns needed: Branch, Ticket ID, Added Time. Only Chennai and ROTN rows are used. The file may hold several months (e.g. from 19 May till today); a ticket from any of those months counts as a review. Only the current month forms the denominator.

Franchise report: Calls Registered file (optional, daily)

Choose the “Calls Registered – All call Type” Excel file. It must contain the Chennai and ROTN branches (or select two files, one per branch, together). The report uses the review data from the file above, or the current data on the website if you did not choose one. Large files can take up to a minute to read.

3. Publish

On GitHub open your repository → click data.json → pencil/“Upload files” → replace it (and report.json, if you made one) with the files you just downloaded → Commit changes. The website updates within about a minute.
